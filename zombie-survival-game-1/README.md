# Zombie Survival Game

## Overview
Zombie Survival Game is a web-based top-down shooter set in a post-apocalyptic world overrun by zombies. Players take on the role of a survivor, battling against waves of zombies while earning points for each one defeated. The game features a variety of weapons, increasing difficulty levels, and engaging gameplay mechanics.

## Features
- **Top-Down View**: Experience the game from a top-down perspective, allowing for strategic movement and combat.
- **Randomly Spawning Zombies**: Zombies spawn at random locations, providing a dynamic challenge for players.
- **Multiple Weapons**: Choose from four unique weapons:
  - **Katana**: High damage with fast attack speed.
  - **Bare Hands**: Quick attacks but lower damage.
  - **Wizard Book**: Magical attacks with burn effects.
  - **Dual Gun**: Rapid-fire with explosive effects.
- **Level-Based Gameplay**: Survive against increasing waves of zombies, with each wave introducing tougher enemies and higher points.
- **Collision Detection**: Accurate detection of interactions between the player, zombies, and the environment.
- **Camera Following**: The camera smoothly follows the player, enhancing the gameplay experience.
- **Visual Effects**: Engaging visual effects for attacks and damage.
- **User Interface**: Includes a start menu, HUD for health and score, and a tutorial for new players.

## Getting Started
To run the game locally, follow these steps:

1. **Clone the Repository**:
   ```
   git clone <repository-url>
   ```

2. **Navigate to the Project Directory**:
   ```
   cd zombie-survival-game
   ```

3. **Open `index.html`**:
   Open the `src/index.html` file in your web browser to start the game.

## Gameplay Instructions
- Use the arrow keys or WASD to move your character.
- Select your weapon from the menu and use it to attack zombies.
- Survive as long as possible while defeating zombies to earn points.
- Keep an eye on your health and manage it wisely.
